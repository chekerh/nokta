# Nokta — Growth Plan

## Growth Philosophy

Nokta grows through developer trust, not marketing spend. Every user who installs Nokta and has a good experience becomes a multiplier — sharing it with their team, writing about it, mentioning it in conversations.

The growth strategy prioritizes:

1. **Product-led growth** — the product is the best marketing
2. **Community building** — developers trust other developers
3. **Content flywheel** — technical content drives SEO + credibility
4. **Ecosystem development** — `.ai/trail/` becoming a standard

---

## Growth Model

```
Install → Activation → Value → Habit → Referral → Team Adoption → Enterprise
```

Each stage requires the previous stage to work. Skip steps at your peril.

### Stage 1: Install

**Metric:** npm downloads
**Driver:** SEO, social, community mentions, word of mouth

### Stage 2: Activation

**Metric:** First successful `nokta init` + first AI session with compiled context
**Driver:** Painless install, immediate "aha moment"
**Target:** 80% of installers activate

### Stage 3: Value

**Metric:** First decision recorded, first quality gate triggered, first sprint created
**Driver:** In-app guidance, onboarding checklist
**Target:** 60% of activated users reach first value event within 7 days

### Stage 4: Habit

**Metric:** Active users returning 3+ days/week
**Driver:** Clear daily workflow benefit (morning standup from trail, AI sessions that work)
**Target:** 40% of value users become habitual

### Stage 5: Referral

**Metric:** NPS score, referral rate
**Driver:** Sharing button in dashboard, team context feature
**Target:** NPS > 40, 20% referral rate

### Stage 6: Team Adoption

**Metric:** Teams with 3+ users
**Driver:** Team context sharing, shared capability packs
**Target:** 20% of habitual users have a team using Nokta

### Stage 7: Enterprise

**Metric:** Enterprise inquiries, signed Enterprise customers
**Driver:** Compliance documentation, SSO, self-hosted
**Target:** 5% of team adoptions convert to Enterprise

## Growth Channels

### Channel 1: SEO + Content (Primary, Long-term)

**Goal:** Become the definitive resource on "AI context management" and "developer workflow optimization"

**Content strategy:**

- 2 blog posts/month on technical topics related to Nokta's domain
- Target keywords:
  - "context compilation for AI coding tools"
  - "AI coding assistant project memory"
  - "developer workflow optimization"
  - "AI productivity for developers"
  - "autonomous coding agents"
  - "local-first developer tools"

**Implementation:**

- Write 1 long-form technical post/month (2,000-4,000 words)
- Write 2 shorter tutorial posts/month (800-1,200 words)
- Publish as GitHub Pages or docs site with clear SEO metadata

### Channel 2: Community & Social (Primary, Ongoing)

**Goal:** Build genuine relationships in developer communities

**Strategy:**

- Active on Twitter/X, LinkedIn, Hacker News, Reddit
- Engage 2-3x more than we post
- Share real wins and honest failures
- Help people solve problems, not just promote Nokta

**Tactics:**

- Share every new feature with demo GIF/video
- Post weekly "what we learned" updates
- Respond to every GitHub issue and Discord message within 24 hours
- Do AMAs in developer communities when relevant

### Channel 3: Ecosystem Integration (Medium-term)

**Goal:** Make `.ai/trail/` a recognized standard that AI tool developers support

**Strategy:**

- Write an open spec for `.ai/trail/` protocol
- Approach AI tool developers (Cursor, Cline, etc.) to support the protocol
- Create VS Code / JetBrains plugins for context display
- Submit to platform marketplaces (VS Code marketplace, etc.)

**Implementation:**

- Open-source the `.ai/trail/` spec as a proper standard
- Build reference implementations for popular tools
- Attend/present at AI developer tool conferences

### Channel 4: Developer Tool Partnerships (Long-term)

**Goal:** Integration partnerships that drive mutual value

**Targets:**

- Vercel, Netlify (deployment platforms that could pre-install Nokta)
- GitHub, GitLab (code hosts that could surface trail context)
- Linear, Jira (project management tools Nokta could integrate with)
- AI providers (OpenAI, Anthropic) — get Nokta context compilation as a featured integration

### Channel 5: Enterprise Sales (Medium-term)

**Goal:** Convert team and enterprise prospects through targeted outreach

**Strategy:**

- Identify companies where developers are already talking about Nokta
- Reach out with genuine offer to help, not hard sell
- Provide trial access to Enterprise with hands-on support
- Use case studies from team customers to inform enterprise messaging

## Retention Strategy

### Daily Active Users

**Tactic:** Make Nokta's morning standup output genuinely useful

- Trail summary that fits in 2 minutes of reading
- Yesterday's AI-assisted changes clearly documented
- Today's priority items auto-populated

### Weekly Active Users

**Tactic:** Make sprint review meaningful

- Weekly report that's more useful than what they'd generate manually
- Decision audit showing patterns worth revisiting
- Gate performance summary

### Monthly Active Users

**Tactic:** Show accumulated value

- "Your team made 47 decisions this month, here's the pattern"
- "AI caught 23 quality violations before code review"
- "Context usage is down 62% compared to last month"

## Key Metrics (KRIs and KPIs)

### Primary KPIs

- Monthly Active Users (MAU) — target 10x in 12 months
- Monthly Recurring Revenue (MRR) — target $30K in 12 months
- Net Promoter Score (NPS) — target >40

### Leading Indicators

- npm downloads/week
- Activation rate (% of installers who run `nokta init`)
- First-value-event rate (% who hit "aha moment")
- Time to first value (from install to first compiled context)

### Lagging Indicators

- Churn rate (monthly, target <5%)
- LTV (target >3x CAC)
- Referral rate (target 20% of new users come from referrals)

---

## Assumptions

1. Developer tools grow through product quality and community trust, not paid ads
2. The best growth marketing is making the product worth recommending
3. Enterprise will come from team adoption, not cold outreach
4. `.ai/trail/` as an open standard is the long-term competitive moat
5. NPS >40 is achievable with a product that genuinely solves the problem
6. Self-serve + community support is sufficient for Pro tier (Enterprise needs dedicated CS)
