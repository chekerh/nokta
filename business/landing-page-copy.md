## How It Works Section

**Step 1: Install**

```
npm install nokta-ai
nokta init
```

Five minutes. No account required. No cloud dependency.

**Step 2: Nokta learns your project**
Nokta scans your codebase, reads your git history, and compiles everything — architecture, patterns, decisions, team standards — into compact, optimized context files in `.ai/trail/`.

**Step 3: Every AI tool reads the same context**
Cursor, Claude Code, Codex, any tool that supports `.ai/trail/` — they all read the same compiled context. Your team standards become the default for every AI interaction.

**Step 4: AI works within your gates**
Before any AI-assisted change ships, Nokta's quality gates verify it follows your standards. Security gates scan for vulnerabilities. Cost gates prevent runaway token usage.

## FAQ Section

**Is this only for teams?**
No. Solo developers get just as much value — Nokta's context compilation and decision tracking are especially powerful when you're the only person working on a project.

**Does this work with my current AI tools?**
Yes. Nokta's `.ai/trail/` protocol is read by Cursor, Claude Code, Codex, and any tool that supports it. If your tool doesn't support it yet, Nokta provides a context compiler that injects compiled context into any AI workflow.

**Is my code sent to your servers?**
Never. Nokta runs entirely locally. Your code, your context, your costs — nothing is sent to any third party.

**How does token optimization work?**
Nokta's compiler scans your project and extracts only the context relevant to your current task — removing noise, deduplicating knowledge, and compressing patterns. This typically reduces token usage by 50-70% while _increasing_ context quality.

**What's the setup time?**
Five minutes. `npm install`, `nokta init`, done. Nokta auto-detects your stack and compiles initial context automatically.

**Can I self-host?**
Yes. Enterprise tier includes full self-hosted deployment with no dependency on Nokta's servers.
